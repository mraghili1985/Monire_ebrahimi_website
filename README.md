## 🌟 ویژگی‌های وب‌سایت (Key Features)

- **طراحی مدرن و مینیمال (B&B Studio & Pearlfisher Standard):** تایپوگرافی تمیز، ساختار روایت‌محور (Challenge → Insight → Solution → Impact)
- **آزمایشگاه سه‌بعدی تعاملی بسته‌بندی (Interactive 3D Lab):**
  - شبیه‌سازی ۳ بعدی جعبه بیسکویت خرمایی شاهنگ با قابلیت چرخش ۳۶۰ درجه آزاد با ماوس و لمس
  - سوییچ لحظه‌ای بین حالت جعبه ۳ بعدی و نقشه گسترده تیغ چاپ صنعتی (Unfold CAD Dieline)
- **پالت رنگی اختصاصی (Lavender × Warm Beige):**
  - تم روشن پیش‌فرض استودیویی (`#FAF8F5`) + تم تاریک لوکس لوح سنگی (`#0F0E13`)
  - قابلیت سوئیچ آنی ۱ کلیکه تم لایت / دارک
- **دو زبانه کامل (Bilingual FA / EN):**
  - پشتیبانی یکپارچه از زبان فارسی (RTL با فونت Vazirmatn) و انگلیسی (LTR با فونت Plus Jakarta Sans)
- **ویترین پروژه‌ها (Curated Showcase & Archive):**
  - دسته‌بندی پروژه‌ها بر اساس بسته‌بندی (Packaging)، برچسب (Label)، هویت بصری (Branding)، بیلبورد (Billboard) و عکاسی صنعتی (Photography)
  - مودال جزئیات پروژه (Case Study Modal) شامل مشخصات متریال، روش چاپ، کدهای رنگی و گالری تصاویر
- **افکت‌های عمق فیزیکی ۳ بعدی (3D Parallax Tilt):** واکنش کارت‌ها به حرکت نشانگر ماوس
- **آماده استقرار روی GitHub Pages**

## 🚀 نحوه اجرا به صورت محلی (Local Run)

می‌توانید فایل `index.html` را مستقیماً در مرورگر باز کنید، یا با اجرای یک سرور سبک محلی:

```bash
# پایتون
python -m http.server 4173

# سپس در مرورگر باز کنید:
# http://localhost:4173
```
